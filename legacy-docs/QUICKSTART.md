## 🎯 Getting Started (3 Steps)

### Step 1: Add Your API Key
1. Click **Settings** in the navigation
2. Go to **API Keys** tab
3. Paste your API key (get from provider's website):
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/settings/keys
   - **Google AI**: https://makersuite.google.com/app/apikey
4. Click **Save API Keys**
5. Select your preferred provider and model

### Step 2: Create Your First Project
1. Go to **Dashboard**
2. Click a template: **eBook**, **Course**, or **Guide**
3. Give it a title
4. Start writing!

### Step 3: Use AI Triggers
While writing, type these anywhere in your content:

| Trigger | Action | Example |
|---------|--------|---------|
| `++` | Expand text | "AI is useful `++`" → expands into detail |
| `>>` | Continue writing | "Once upon a time `>>`" → continues story |
| `??` | Improve text | "bad grammer `??`" → fixes & improves |
| `//` | Get suggestions | "Need ideas for `//`" → provides ideas |
| `@@` | Research topic | "quantum physics `@@`" → explains topic |

## 🆘 Troubleshooting

### "API Key Missing" Error
**Solution**: Go to Settings → API Keys, add your key, and click Save

### AI Triggers Not Working
**Possible causes**:
1. No API key configured
2. Invalid API key (check provider website)
3. Network issues (check connection)

**Solution**: Test API key in Settings, verify it's active

### Projects Not Saving
**Possible causes**:
1. Browser storage full
2. IndexedDB disabled
3. Private/Incognito mode

**Solution**: Check browser storage settings, use regular mode

### Dark Mode Too Dark/Light
**Solution**: This is optimized for high contrast. If needed:
1. Adjust screen brightness
2. Use browser zoom (⌘+/⌘- or Ctrl+/Ctrl-)

### Slow Performance
**Possible causes**:
1. Too many projects (50+)
2. Very large content (100k+ words)
3. Browser extensions

**Solution**: Export old projects, close other tabs, disable extensions
